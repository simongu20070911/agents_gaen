# Documentation Index

This folder curates high-signal documentation and provides an index for the broader research stack. Each sub-project also ships with its own docs; the goal here is to make everything discoverable from a single place.

## Primary references

- [`docs/development.md`](development.md) – Development workflows, testing commands, and environment expectations.
- [`docs/architecture.md`](architecture.md) – High-level system overview and module responsibilities.
- [`docs/artifact_catalog.md`](artifact_catalog.md) – Directory-by-directory catalog of data, scripts, and supporting assets.

## Cross-references

- `department_of_market_intelligence/docs/` – Internal ULTRATHINK manuals, agent specs, and prompt inventories.
- `solver/README.md` – IMO solver usage details.
- `adk-docs/docs/` – Gemini ADK documentation and runnable samples.
- `AGENTS.md` – Legacy notes on agent personas; retained at repo root for backwards compatibility.

If you are onboarding, start with `architecture.md`, then follow the checklists in `development.md` to configure your environment and run validation passes.
