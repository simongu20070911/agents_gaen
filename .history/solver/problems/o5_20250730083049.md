\section*{5. For ALL APPLICANTS.}

Define the sequence, $F_n$, as follows: $F_1 = 1, F_2 = 1$, and for $n \ge 3$,
\[ F_n = F_{n-1} + F_{n-2}. \tag{*} \]

\begin{enumerate}
    \item[(i)] [3 marks] What are the values $F_3, F_4, F_5$?
    
    \item[(ii)] [1 mark] Using the equation (*) repeatedly, in terms of $n$, how many additions do you need to calculate $F_n$?
\end{enumerate}

We now consider sequences of 0's and 1's of length $n$, that do not have two consecutive 1's. So, for $n = 5$, for example, $(0, 1, 0, 0, 1)$ and $(1, 0, 1, 0, 1)$ would be valid sequences, but $(0, 1, 1, 0, 0)$ would not. Let $S_n$ denote the number of valid sequences of length $n$.

\begin{enumerate}
    \item[(iii)] [1 mark] What are $S_1$ and $S_2$?
    
    \item[(iv)] [3 marks] For $n \ge 3$, by considering the first element of the sequence of 0's and 1's, show that $S_n$ satisfies the same equation (*). Hence conclude that $S_n = F_{n+2}$ for all $n$.
    
    \item[(v)] [2 marks] For $n \ge 2$, by considering valid sequences of length $2n-3$ and focusing on the element in the $(n-1)^{th}$ position, show that,
    \[ F_{2n-1} = F_n^2 + F_{n-1}^2. \tag{O} \]
    
    \item[(vi)] [3 marks] For $n \ge 2$, show that,
    \[ F_{2n} = F_n^2 + 2F_n F_{n-1}. \tag{E} \]
    
    \item[(vii)] [2 marks] Let $k \ge 3$ be an integer. By using the equations (O) and (E) repeatedly, how many arithmetic operations do you need to calculate $F_{2^k}$? You should only count additions and multiplications needed to calculate values using the equations (O) and (E).
\end{enumerate}
